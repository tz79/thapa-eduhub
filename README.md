# Thapa EduHub

A responsive, multi-page educational website built using HTML and CSS. Thapa EduHub presents an online learning platform where visitors can explore courses, learn about the platform, read blog posts, and contact the team.

This project was developed as a learning and practice project by following **Thapa Technical's CSS Course Part 2**.

## Features

- **Home Page:** Hero section, introduction, featured courses, why-choose-us section, and contact call-to-action.
- **About Page:** Information about the platform's research, design, and development process.
- **Services Page:** Course cards for JavaScript, Python, C++, Java, SQL, HTML, and CSS.
- **Blog Page:** Blog cards with images, dates, and article links.
- **Contact Page:** Contact form and embedded Google Map.
- **Responsive Layout:** Media queries for different screen sizes.
- **Animations:** Scroll animations using AOS.
- **Interactive Styling:** Hover effects, transitions, and CSS animations.

## Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling and responsive layouts.
- **CSS Grid** – Multi-column layouts.
- **Flexbox** – Flexible alignment and navigation.
- **CSS Custom Properties** – Reusable theme colors and variables.
- **CSS Nesting** – Organized and nested styling rules.
- **Media Queries** – Responsive design.
- **Google Fonts** – Jost, Poppins, and Urbanist.
- **Font Awesome** – Icons.
- **AOS (Animate On Scroll)** – Scroll-based animations.
- **Formspree** – Contact form submission.
